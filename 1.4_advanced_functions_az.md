# 1.4: Data Processing üçün Advanced Functions və Functional Programming

## Functional Programming nədir?

Functional Programming (FP) — kompüter proqramlarının strukturunu və elementlərini qurma üslubu olan programming paradigm-dir; o, hesablamanı riyazi function-ların qiymətləndirilməsi (evaluation) kimi qəbul edir və dəyişən state-dən (changing-state) və mutable datadan çəkinir.

Data processing üçün aktual olan əsas prinsiplər:

*   **Pure Functions:** Pure function-ın return value-su eyni argument-lər üçün həmişə eynidir. Onun side effect-i yoxdur, yəni function-dan kənardakı heç bir state-i dəyişmir (məsələn, global variable-ı dəyişmək və ya console-a çap etmək). Bu, kodu daha proqnozlaşdırıla bilən və test etməyi asanlaşdıran edir.
*   **Immutability:** Data immutable kimi qəbul edilir, yəni yaradıldıqdan sonra dəyişdirilə bilməz. Mövcud data structure-ları dəyişmək əvəzinə yenilərini yaradırsınız. Bu, istənilməyən data dəyişikliklərindən yaranan bug-ların qarşısını almağa kömək edir.
*   **First-Class Functions:** Function-lara hər hansı digər variable kimi yanaşılır. Onları başqa function-lara argument kimi ötürmək, function-lardan return etmək və variable-lara mənimsətmək olar.
*   **Avoiding Side Effects:** Functional programming side effect-ləri (function-ın scope-undan kənardakı state dəyişikliklərini) minimuma endirməyi hədəfləyir.

Data science-də `lambda`, `map` və `filter` kimi alətlərlə functional prinsiplərin tətbiqi data transformation və processing pipeline-ları üçün daha qısa, oxunaqlı və daha az xəta ehtimallı kod yaranmasına səbəb olur.

## Lambda Functions

Lambda function-lar `lambda` keyword-ü ilə təyin edilən kiçik, anonim (anonymous) function-lardır. Onlar istənilən sayda argument qəbul edə bilər, lakin yalnız bir expression-a malik olur.

**Əsas ideya:** Kiçik, birdəfəlik tapşırıq üçün niyə `def` ilə tam function təyin edək? Lambda function — qısayoldur.

**Syntax:** `lambda arguments: expression`

**Example:** İki ədədi toplayan function.
```python
def add_def(a, b):
    result = a + b
    return result
print(add_def(5, 3))  # Output: 8
```

Daha sadə, lakin ekvivalent function:
```python
def add_def(a, b):
    return a + b
print(add_def(5, 3))  # Output: 8
```

Eyni function-ı tək sətirdə də yaza bilərsiniz:

```python
def add_def(a, b): return a + b
print(add_def(5, 3))  # Output: 8
```

Lambda function eyni function-ı yazmağın daha qısa yoludur:
```python
add = lambda a, b: a + b
print(add(5, 3))  # Output: 8
```

**Lambda Functions nə vaxt istifadə olunur?**

Onlar qısa müddət üçün kiçik function-a ehtiyac olduqda, çox vaxt higher-order function-a (digər function-ları argument kimi qəbul edən function-a), məsələn `map`, `filter` və ya `sorted`-ə argument kimi ötürüləndə ən faydalıdır.

**`sorted()` ilə nümunə:**

```python
# Tuple-lardan ibarət list (name, age)
people = [('Alice', 30), ('Bob', 25), ('Charlie', 35)]

# Yaşa görə sıralayın (tuple-ın ikinci elementi)
sorted_people = sorted(people, key=lambda person: person[1])
print(sorted_people)  # Output: [('Bob', 25), ('Alice', 30), ('Charlie', 35)]
```

Burada `lambda person: person[1]` `sorted`-ə sıralama üçün yaşdan istifadə etməyi deyən qısa function-dır.

## `map`, `filter`, və `reduce`

Bunlar function-ları sequence-lərə (list kimi) tətbiq etməyə imkan verən üç güclü function-dır.

### `map()`

`map()` function-ı verilmiş function-ı iterable-ın (məsələn, list-in) hər elementinə tətbiq edir və `map` obyekti (iterator) qaytarır.

**Syntax:** `map(function, iterable)`

**Example:** List-dəki hər rəqəmin kvadratını almaq.

```python
numbers = [1, 2, 3, 4]
squared_numbers = map(lambda x: x**2, numbers)

# Nəticəni görmək üçün map obyektini list-ə çevirin
print(list(squared_numbers))  # Output: [1, 4, 9, 16]
```

### `filter()`

`filter()` function-ı iterable-ın elə elementlərindən iterator yaradır ki, verilmiş function onlar üçün `True` qaytarsın.

**Syntax:** `filter(function, iterable)`

**Example:** List-dən cüt (even) rəqəmləri süzgəcdən keçirmək.

```python
numbers = [1, 2, 3, 4, 5, 6]
even_numbers = filter(lambda x: x % 2 == 0, numbers)

# Filter obyektini list-ə çevirin
print(list(even_numbers))  # Output: [2, 4, 6]
```

### `reduce()`

`reduce()` function-ı iki argument-li function-ı iterable-ın elementlərinə soldan sağa kumulyativ (cumulatively) şəkildə tətbiq edərək iterable-ı tək dəyərə endirir (reduce). O, `functools` module-unun tərkibindədir.

**Syntax:** `functools.reduce(function, iterable)`

**Example:** List-dəki bütün rəqəmlərin hasilini hesablamaq.

```python
from functools import reduce

numbers = [1, 2, 3, 4]
product = reduce(lambda x, y: x * y, numbers)
print(product)  # Output: 24 (1*2=2, 2*3=6, 6*4=24)
```

> **Note:** Digər function-ları argument kimi qəbul edən function-lar higher-order function adlanır. `map`, `filter` və `reduce` hamısı higher-order function-dır. Function-ları başqa function-lara argument kimi ötürməklə öz higher-order function-larımızı da yarada bilərik.
> ```python
> def apply_function(func, value):
>     return func(value)
> 
> def square(x):
>     return x**2
> 
> def cube(x):
>     return x**3
> 
> print(apply_function(square, 5))  # Output: 25
> print(apply_function(cube, 5))  # Output: 125
> ```


## List Comprehensions

List comprehension-lar list yaratmağın qısa yolunu təqdim edir. Onlar çox vaxt `for` loop-lardan daha oxunaqlı və performanslı olur.

**Basic Syntax:** `[expression for item in iterable]`

**Example:** Kvadratlar list-i yaratmaq.

```python
# for loop istifadə etməklə
squares_loop = []
for i in range(5):
    squares_loop.append(i**2)

# List comprehension istifadə etməklə
squares_comp = [i**2 for i in range(5)]

print(squares_comp)  # Output: [0, 1, 4, 9, 16]
```

### Adding a Condition

Elementləri süzgəcdən keçirmək üçün `if` condition əlavə edə bilərsiniz.

**Syntax:** `[expression for item in iterable if condition]`

**Example:** Yalnız cüt rəqəmlərin kvadratlarını almaq.

```python
even_squares = [i**2 for i in range(10) if i % 2 == 0]
print(even_squares)  # Output: [0, 4, 16, 36, 64]
```

### `if-else` in List Comprehensions

`if-else` statement-dən də istifadə edə bilərsiniz.

**Syntax:** `[expression if condition else other_expression for item in iterable]`

**Example:** Rəqəmləri 'even' və ya 'odd' kimi etiketləmək (label).

```python
labels = ['even' if i % 2 == 0 else 'odd' for i in range(5)]
print(labels)  # Output: ['even', 'odd', 'even', 'odd', 'even']
```

> **Exercise:** Celsius temperaturlarından ibarət list-i Fahrenheit temperaturlarına çevirmək üçün list comprehension istifadə edin.

## Dictionary and Set Comprehensions

List comprehension-lara bənzər şəkildə dictionary və set-ləri də qısa yolla yarada bilərsiniz.

### Dictionary Comprehensions

**Syntax:** `{key_expression: value_expression for item in iterable}`

**Example:** Rəqəmlər və onların kvadratlarından ibarət dictionary yaratmaq.

```python
squared_dict = {x: x**2 for x in range(5)}
print(squared_dict)  # Output: {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}
```

### Set Comprehensions

**Syntax:** `{expression for item in iterable}`

**Example:** Təkrarlanan elementləri olan list-dən unikal kvadratlardan ibarət set yaratmaq.

```python
numbers = [1, 2, 2, 3, 3, 3, 4]
unique_squares_set = {x**2 for x in numbers}
print(unique_squares_set)  # Output: {1, 4, 9, 16}
```

> **Note:** Python-da list comprehension-lar kimi birbaşa "tuple comprehension" syntax-ı yoxdur. Oxşar yanaşma ilə tuple yaratmaq üçün generator expression-dan (mötərizələrlə) istifadə edib onu `tuple()` constructor-una ötürməlisiniz.
> ```python
> unique_squares_tuple = tuple(x**2 for x in numbers)
> print(unique_squares_tuple)  # Output: (1, 4, 9, 16)
> ```

## Error Handling (`try...except`)

Xətalar (errors) və ya exception-lar proqramlarda qaçılmazdır. Error handling proqramınıza crash etmədən bu exception-ları səliqəli şəkildə idarə etməyə imkan verir.

Bunun üçün `try...except` bloku istifadə olunur.
- `try` bloku exception yarada biləcək kodu ehtiva edir.
- `except` bloku exception baş verərsə icra olunan kodu ehtiva edir.
- `else` bloku try blokunda exception baş verməzsə icra olunan kodu ehtiva edir.
- `finally` bloku exception baş verib-verməməsindən asılı olmayaraq həmişə icra olunan kodu ehtiva edir.

Syntax:
```python
try:
    # exception yarada biləcək kod
except ExceptionType:
    # exception baş verərsə icra olunacaq kod
else:
    # try blokunda exception baş verməzsə icra olunacaq kod
finally:
    # exception baş verib-verməməsindən asılı olmayaraq həmişə icra olunan kod
```

> **Note:** `ExceptionType` baş verən exception-ın növüdür. Heç bir exception type istifadə etməyə, konkret exception type-dan istifadə etməyə və ya bütün exception-ları tutmaq üçün ümumi `Exception` type-dan istifadə etməyə bilərsiniz.
> ```python
> except ExceptionType as e:
>     # exception baş verərsə icra olunacaq kod və exception-ı variable-a mənimsət
> except ExceptionType:
>     # exception-ı variable-a mənimsətmədən
> except Exception as e:
>     # ümumi exception handling
> except:
>     # bütün exception-lar üçün
> ```

**Example:** Sıfıra bölməni (division by zero) idarə etmək.

```python
try:
    result = 10 / 0
except ZeroDivisionError:
    result = "You can't divide by zero!"

print(result) # Output: You can't divide by zero!
```

### Handling Multiple Exceptions

Müxtəlif növ exception-ları idarə edə bilərsiniz.

```python
try:
    num = int(input("Enter a number: "))
    result = 10 / num
except ValueError:
    print("That was not a valid number!")
except ZeroDivisionError:
    print("You can't divide by zero!")
```

### `else` and `finally` clauses

- `else`: Bu blok yalnız `try` blokunda heç bir exception baş vermədikdə icra olunur.
- `finally`: Bu blok exception baş verib-verməməsindən asılı olmayaraq hər halda icra olunur. O, çox vaxt fayl bağlamaq kimi təmizləmə (cleanup) əməliyyatları üçün istifadə olunur.

**Example:**

```python
try:
    num = int(input("Enter a number: "))
except ValueError:
    print("Invalid input.")
else:
    print(f"You entered {num}.")
finally:
    print("Execution finished.")
```

## Raising Exceptions (`raise`)

Bəzən kodunuzda müəyyən şərt ödənilmədikdə qəsdən exception raise etməlisiniz. Bunun üçün `raise` keyword-ü istifadə olunur.

**Example:** Yalnız müsbət rəqəmləri qəbul edən function.

```python
def process_positive_number(n):
    if n <= 0:
        raise ValueError("The number must be positive!")
    print(f"{n} is a valid number.")

try:
    process_positive_number(10)   # Bu işləyəcək
    process_positive_number(-5)   # Bu xəta raise edəcək
except ValueError as e:
    print(f"Error: {e}")

# Output:
# 10 is a valid number.
# Error: The number must be positive!
```

Exception raise etməklə nəyinsə səhv getdiyini bildirə bilərsiniz və bu, `except` bloku tərəfindən tutulub (catch) idarə oluna bilər.

## Assertions

Assertion-lar şərtin doğru olub-olmadığını yoxlama üsuludur. Şərt yalnışdırsa (false), `AssertionError` raise olunur. Onlar kodda heç vaxt baş verməməli olan xətaları tutmaq üçün istifadə olunur.

**Syntax:** `assert condition, message`

**Example:**

```python
assert 1 == 1, "1 is not equal to 1"
```
