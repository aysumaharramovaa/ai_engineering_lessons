## Dictionaries

Dictionary — key-value pair-lər şəklində saxlanılan sıralı (ordered) data kolleksiyasıdır (Python 3.7-yə qədər sırasız idi). Dictionary-lər mutable-dır və hər key unikal olmalıdır.

### Creating Dictionaries

Dictionary yaratmaq üçün fiqurlu mötərizələrdən `{}` istifadə edirsiniz; key-lər və value-lar iki nöqtə `:` ilə ayrılır.

```python
person = {
    "key1": "value1",
    "key2": "value2",
    "key3": "value3",
}
```

**Example**:
```python
# Şəxsi təmsil edən dictionary
person = {
    "name": "Alice",
    "age": 25,
    "city": "New York"
}
```

### Accessing Values

Key-ə aid value-ya kvadrat mötərizələr `[]` ilə daxil olursunuz.

```python
print(person["name"])  # Output: Alice
print(person["age"])   # Output: 25
```

### Modifying Dictionaries

*   **Value-nu dəyişmək (Changing a value):**
    ```python
    person["age"] = 26
    print(person) # Output: {'name': 'Alice', 'age': 26, 'city': 'New York'}

    person["age"] = person["age"] + 1
    print(person) # Output: {'name': 'Alice', 'age': 27, 'city': 'New York'}
    ```
*   **Yeni key-value pair əlavə etmək (Adding a new key-value pair):**
    ```python
    person["occupation"] = "Engineer"
    print(person) # Output: {'name': 'Alice', 'age': 26, 'city': 'New York', 'occupation': 'Engineer'}
    ```
*   **Key-value pair silmək (Removing a key-value pair):**
    ```python
    del person["city"]
    print(person) # Output: {'name': 'Alice', 'age': 26, 'occupation': 'Engineer'}
    ```

### More complex dictionaries

Value-su dictionary olan dictionary yarada bilərsiniz.

```python
company = {
    "names": ["Alice", "Bob", "Charlie"],
    "ages": [25, 30, 35],
    "addresses": {
        "Alice": {"city": "New York", "state": "NY"},
        "Bob": {"city": "Los Angeles", "state": "CA"},
        "Charlie": {"city": "Chicago", "state": "IL"}
    }
}

print(company["names"][0]) # Output: Alice
print(company["addresses"]["Alice"]["city"]) # Output: New York
```

### Operations on Dictionaries

*   **Bütün key-ləri əldə etmək (Getting all keys):**
    ```python
    print(person.keys()) 
    ```
*   **Bütün value-ları əldə etmək (Getting all values):**
    ```python
    print(person.values()) 
    ```
*   **Bütün key-value pair-ləri əldə etmək (Getting all key-value pairs):**
    ```python
    print(person.items()) 
    ```
*   **Key-in mövcud olub-olmadığını yoxlamaq (Checking if a key exists):**
    ```python
    print("name" in person) # Output: True
    ```
*   **Value-nun mövcud olub-olmadığını yoxlamaq (Checking if a value exists):**
    ```python
    print("Alice" in person.values()) # Output: True
    ```
*   **Key-in value-sunu default value ilə əldə etmək (Getting the value of a key with a default value):**
    ```python
    print(person.get("height", "Unknown")) # Output: Unknown
    ```

## Sets

Set — **unikal** elementlərin sırasız (unordered) və index-siz (unindexed) kolleksiyasıdır. Set-lər mutable-dır.

### Creating Sets

Set-i `set()` function-ı ilə yarada bilərsiniz
```python
numbers = set(1, 2, 2, 3, 4, 4, 5)
print(unique_numbers)  # Output: {1, 2, 3, 4, 5}
```

> **Note:** Set-lər dictionary-lərə bənzər şəkildə fiqurlu mötərizələrlə `{}` təyin olunur, lakin key-value pair-lər olmadan.

Set-i mövcud list-dən də yarada bilərsiniz,
```python
numbers = [1, 2, 2, 3, 4, 4, 5]
unique_numbers = set(numbers)
print(unique_numbers)  # Output: {1, 2, 3, 4, 5}
```

> **Note:** Set-lər sırasızdır (unordered), ona görə də elementlərə index ilə daxil ola bilməzsiniz.

Set-ə `add()` method-u ilə element əlavə edə bilərsiniz.

```python
numbers.add(6)
print(numbers)  # Output: {1, 2, 3, 4, 5, 6}
```

### Set Operations

Set-lər riyazi çoxluq (set) əməliyyatlarını yerinə yetirmək üçün faydalıdır.

```python
set_a = {1, 2, 3, 4}
set_b = {3, 4, 5, 6}

# Union: hər iki set-dən ən azı birində olan elementlər
print(set_a.union(set_b))  # Output: {1, 2, 3, 4, 5, 6}

# Intersection: hər iki set-də olan elementlər
print(set_a.intersection(set_b))  # Output: {3, 4}

# Difference: set_a-da olan, lakin set_b-də olmayan elementlər
print(set_a.difference(set_b))  # Output: {1, 2}
```

## Introduction to Functions

Function — müəyyən tapşırığı yerinə yetirən təkrar istifadə oluna bilən kod blokudur. Function-lar kodunuzu təşkil etməyə, onu daha oxunaqlı etməyə və təkrarçılığın qarşısını almağa kömək edir.

### Writing and Calling Functions

Function-ı `def` keyword-ü ilə, ardınca function adı, mötərizələr `()` və iki nöqtə `:` yazaraq təyin edirsiniz (define).

```python
# Function-ı təyin edin (define)
def greet():
    print("Hello, welcome to the course!")

# Function-ı çağırın (call)
greet()
```

## Function Arguments

Argument-lər function-lara məlumat ötürmək üçün istifadə olunur.

```python
def greet_user(name):
    print(f"Hello, {name}!")

greet_user("Bob")
```

### Positional Arguments

Bunlar düzgün sırada olmalı olan argument-lərdir.

```python
def greet_user(name, course):
    print(f"Hello, {name}! Welcome to the {course} course.")

greet_user("Bob", "Python for Data Science")
```

### Keyword Arguments

Argument-ləri parameter-in adından istifadə edərək də ötürə bilərsiniz.

```python
greet_user(course="Data Analysis", name="Charlie")
```

Keyword argument-lər argument üçün default value təyin edə bilər. Bu, function çağırılarkən həmin argument-i optional edir.

```python
def greet_user_default(name, course="Python for Data Science"):
    print(f"Hello, {name}! Welcome to the {course} course.")

greet_user_default("David")
greet_user_default("Eve", course="Advanced Python")
```

**Note:** Default argument-lər bütün required argument-lərdən sonra yerləşdirilməlidir.
```python
def greet_user_default(arg1, arg2, arg3="default", arg4="default"):
    pass

greet_user_default()
```

### Using return statement

`return` statement function-dan value qaytarmaq üçün istifadə olunur (bu value sonradan kodun digər hissələrində istifadə oluna bilər). `print` isə value-nu console-a çap edir (və bu, kodun digər hissələrində istifadə oluna bilməz). Aşağıdakı iki nümunəni müqayisə edin:

```python
# print nümunəsi
def add_print(a, b):
    print(a + b)

x = add_print(1, 2) # x is None

def add_return(a, b):
    return a + b

x = add_return(1, 2) # x is 3
```

Function `return` statement icra olunduqdan sonra çıxır (exit). `return` statement-dan sonrakı kod icra olunmur.
```python
def add_return(a, b):
    return a + b
    print("This will not be executed")

x = add_return(1, 2) # x is 3
```

### Adding logic to functions

Daha mürəkkəb tapşırıqları yerinə yetirmək üçün function-lara logic əlavə edə bilərsiniz.
```python
def check_even(number):
    if number % 2 == 0:
        return True
    else:
        return False

print(check_even(2)) # Output: True
print(check_even(3)) # Output: False
```

Rəqəmlər list-i üzərində iterate etmək və onların cüt (even) olub-olmadığını yoxlamaq üçün loop-lardan da istifadə edə bilərsiniz.
```python
def check_even_list(numbers):
    for number in numbers:
        if number % 2 != 0:
            return False
        else:
            pass
    return True

print(check_even_list([2, 4, 6, 8])) # Output: True
print(check_even_list([2, 4, 6, 7])) # Output: False
```

Ehtiyacınız olan tapşırıqları yerinə yetirmək üçün custom function-lar yarada bilərsiniz, məsələn:
```python
# built-in length function
len("Hello") # Output: 5

# custom length function
def length(string):
    count = 0
    for char in string:
        count += 1
    return count
print(length("Hello")) # Output: 5
```

## Scope of Variables

*   **Local Scope:** Function-ın içində yaradılan variable yalnız həmin function daxilində mövcuddur.
*   **Global Scope:** Python kodunun əsas hissəsində (main body) yaradılan variable global variable-dır və global scope-a aiddir; o, bütün function-lar üçün əlçatandır.

```python
global_var = "I am global"

def my_function():
    local_var = "I am local"
    print(local_var)
    print(global_var) # Global variable-lara daxil ola bilər

my_function()
# print(local_var) # Bu, xəta verərdi
```

**Example:**
```python
x = 1000
y = 2000
def my_function(y = 10):
    x = 20
    print(x) # Output: 20
    print(y) # Output: 10
my_function()
print(x) # Output: 1000
print(y) # Output: 2000
```

Function-ın içində global variable-a daxil olmaq üçün `global` keyword-ündən istifadə edə bilərsiniz.
```python
x = 1000
def my_function():
    global x
    x = 20
    print(x) # Output: 20
my_function()
print(x) # Output: 20
```

**Example:**
```python
name = "Bob"

def greet():
    name = "Alice"

    def hello():
        print(f"Hello, {name}!")

    hello()

greet() # Output: Hello, Alice!
```
