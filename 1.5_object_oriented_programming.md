# 1.5: Object-Oriented Programming (OOP)

## Introduction to OOP

### OOP vs. Functional Programming

Object-Oriented Programming (OOP) və Functional Programming (FP) iki fərqli paradigm-dir, yəni kodunuzu necə strukturlaşdıracağınız barədə düşünməyin iki fərqli yoludur.

| Feature             | Object-Oriented Programming (OOP)                                | Functional Programming (FP)                                       |
| ------------------- | ---------------------------------------------------------------- | ----------------------------------------------------------------- |
| **Core Idea**       | Kodu data və davranışı (behavior) birləşdirən object-lərə təşkil edir.       | Hesablamanı riyazi function-ların qiymətləndirilməsi (evaluation) kimi qəbul edir.     |
| **State**           | State-i object-lərin içində encapsulate edərək idarə edir.                | Mutable state-dən çəkinir və ya onu minimuma endirir, immutable datanı üstün tutur.        |
| **Data & Operations** | Data (attribute-lər) və əməliyyatlar (method-lar) bir-biri ilə sıx bağlıdır. | Data və function-lar bir-birindən ayrıdır.                                  |
| **Primary Flow**    | Method-lar object-lər üzərində çağırılır.                                   | Function-lar kompozisiya olunur (compose) və argument kimi ötürülür.                   |
| **Use Cases**       | State-in mərkəzi olduğu böyük, mürəkkəb sistemlər üçün yaxşıdır.          | Data processing, concurrency və riyazi tapşırıqlar üçün əladır. |

Onlar fərqli olsalar da, Python kimi müasir dillər hər iki üslubu qarışdırmağa imkan verir. Məsələn, object-in içində data emal etmək üçün lambda function və `map` istifadə edən method ola bilər. Hər ikisini anlamaq konkret problem üçün ən yaxşı yanaşmanı seçməyə kömək edir.

**Object nədir?**

Real dünyada hər şeyi object kimi düşünmək olar. Avtomobil, it, insan — hamısı object-dir. Hər object-in:
- **Attributes:** Xüsusiyyətləri və ya property-ləri var (məs., avtomobilin rəngi, modeli və ili var).
- **Methods:** Yerinə yetirə biləcəyi hərəkətlər və ya davranışları var (məs., avtomobil `start()`, `drive()` və `stop()` edə bilər).

OOP bu konsepsiyanı programming-ə tətbiq edir. O, kodumuzu real dünya object-lərini modelləşdirəcək şəkildə strukturlaşdırmağa imkan verir və bu da proqramlarımızı daha təşkilatlı, təkrar istifadə oluna bilən və başa düşülən edir.

**OOP niyə istifadə olunur?**

- **Modularity:** Mürəkkəb problemləri kiçik, idarə oluna bilən object-lərə bölür.
- **Reusability:** Object-lər müxtəlif proqramlarda təkrar istifadə oluna bilər (məs., bir dəfə təyin etdiyiniz `Car` object-i avtomobilə ehtiyac duyduğunuz hər yerdə istifadə oluna bilər).
- **Maintainability:** Object-lərə yaxşı təşkil olunmuş kodu yeniləmək və saxlamaq (maintain) daha asandır.

## Creating Classes

**Class** — object-lər yaratmaq üçün plan (blueprint) rolunu oynayır. O, həmin class-ın bütün object-lərinin sahib olacağı attribute-ləri və method-ları təyin edir. **Object** (və ya **instance**) isə həmin plana əsasən yaradılmış konkret nümunədir.

**Belə düşünün:** `CookieCutter` (peçenye qəlibi) class-dır. Onunla hazırladığınız `cookies` (peçenyelər) isə object-lərdir.

### Defining a Class

Class təyin etmək üçün `class` keyword-ü istifadə olunur. Konvensiyaya görə class adları PascalCase ilə yazılır.

```python
class Dog:
    pass

print(Dog)
# Output: <class '__main__.Dog'>
```

Instance class-ın konkret nümunəsidir. O, class adından function kimi istifadə edilərək yaradılır.

```python
class Dog:
    pass

my_dog = Dog()
your_dog = Dog()
print(my_dog)
# Output: <__main__.Dog object at 0x000001A323D42250>
type(my_dog)
# Output: '__main__.Dog'
```

Attribute — object ilə əlaqəli variable-dır. O, class daxilində təyin olunur və class-ın bütün instance-ları tərəfindən paylaşılır. Onu object-in xüsusiyyəti kimi düşünə bilərsiniz.

```python
class Dog:
    # Class attribute (class-ın bütün instance-ları üçün eynidir)
    species = "Canis familiaris"

my_dog = Dog()
print(my_dog.species)
# Output: Canis familiaris
```

Method — object ilə əlaqəli function-dır. O, class daxilində təyin olunur və class-ın bütün instance-ları tərəfindən paylaşılır. Onu object-in davranışı kimi düşünə bilərsiniz.

```python
class Dog:
    # Class attribute (class-ın bütün instance-ları üçün eynidir)
    species = "Canis familiaris"

    # Instance method
    def bark(self):
        return "Woof!"

my_dog = Dog()
print(my_dog.bark())
# Output: Woof!
print(Dog.species)
# Output: Canis familiaris
```

> **Note:** `self` parameter-i class-ın cari instance-ına olan reference-dir. O, class-a aid olan variable-lara daxil olmaq üçün istifadə olunur. O, class-dakı istənilən method-un ilk parameter-i olmalıdır. Texniki cəhətdən `self` parameter-i üçün istədiyiniz adı istifadə edə bilərsiniz, lakin konvensiya `self` istifadə etməkdir.
> ```python
> class Dog:
>     # Class attribute (class-ın bütün instance-ları üçün eynidir)
>     species = "Canis familiaris"
>     
>     # Instance method
>     def bark(this):
>         return "Woof!"
> ```
> `self` parameter-i olmadan method hansı object üzərində çağırıldığını bilməyəcək. Məsələn,
> ```python
> class Dog:
>     # Class attribute (class-ın bütün instance-ları üçün eynidir)
>     species = "Canis familiaris"
>     
>     # Instance method
>     def bark():
>         return "Woof!"
> 
> my_dog = Dog()
> print(my_dog.bark())
> # Output: Error: Dog.bark() takes 0 positional arguments but 1 was given
> print(Dog.bark())
> # Output: Woof!
> ```

Yeni object yaradılanda çağırılan xüsusi `__init__` method-u var. O, object-in attribute-lərini initialize etmək üçün istifadə olunur.

```python
class Dog:
    # Class attribute (class-ın bütün instance-ları üçün eynidir)
    species = "Canis familiaris"

    # Initializer / Instance attribute-ləri
    def __init__(self, name, age):
        self.name = name  # self.name instance attribute-dır
        self.age = age

    # Instance method
    def bark(self):
        return "Woof!"

my_dog = Dog("Buddy", 5)
your_dog = Dog("Lucy", 3)
print(my_dog.name, your_dog.name)
# Output: Buddy Lucy
print(my_dog.age, your_dog.age)
# Output: 5 3
print(my_dog.species, your_dog.species)
# Output: Canis familiaris Canis familiaris
```

> **Note:** Class attribute-ləri class-ın bütün instance-ları tərəfindən paylaşılır. Instance attribute-ləri isə class-ın hər instance-ına xasdır.

Variable `__init__` method-unda initialize edildikdən sonra ona `self` keyword-ü ilə daxil olmaq olar.

```python
class Dog:
    # Class attribute (class-ın bütün instance-ları üçün eynidir)
    species = "Canis familiaris"

    # Initializer / Instance attribute-ləri
    def __init__(self, name, age):
        self.name = name  # self.name instance attribute-dır
        self.age = age

    # Instance method
    def bark(self):
        return "Woof!"

    def describe(self):
        return f"{self.name} is {self.age} years old."

print(my_dog.describe())
# Output: Buddy is 5 years old.
print(your_dog.describe())
# Output: Lucy is 3 years old.
```

**Key Components:**
- **`__init__` method:** Bu xüsusi method "constructor" adlanır. Class-ın yeni object-i yaradılanda icra olunur. O, object-in attribute-lərini initialize etmək üçün istifadə olunur.
- **`self`:** `self` parameter-i class-ın cari instance-ına olan reference-dir. O, class-a aid olan variable-lara daxil olmaq üçün istifadə olunur. O, class-dakı istənilən method-un ilk parameter-i olmalıdır.
- **Attributes:** `name` və `age` hər `Dog` object-inə xas olan instance attribute-lərdir. `species` isə bütün `Dog` object-ləri tərəfindən paylaşılan class attribute-dur.
- **Methods:** `bark()` və `describe()` instance method-lardır, yəni class-ın içində təyin olunan və object üzərində çağırıla bilən function-lardır.

### Creating an Instance (Object)

Class-dan object yaratmaq üçün class-ı function kimi "çağırırsınız" (call).

```python
# İki Dog object-i yaradın
my_dog = Dog("Buddy", 5)
your_dog = Dog("Lucy", 3)

# Attribute-lərə daxil olmaq
print(my_dog.name)   # Output: Buddy
print(your_dog.age)    # Output: 3

# Method-ları çağırmaq
print(my_dog.bark())     # Output: Woof!
print(your_dog.describe()) # Output: Lucy is 3 years old.
```

class Circle:

## Inheritance

Inheritance — yeni class-a (**child class** və ya **subclass**) mövcud class-dan (**parent class** və ya **superclass**) attribute və method-ları miras almağa (inherit) imkan verən mexanizmdir. Bu, kodun təkrar istifadəsini təşviq edir.

**Example:** `Dog`-dan inherit edən `GoldenRetriever` class-ı yaradaq.

```python
class GoldenRetriever(Dog):  # Dog-dan inherit edir
    def fetch(self, item):
        return f"{self.name} is fetching the {item}!"
```

`GoldenRetriever` class-ı avtomatik olaraq `Dog` class-ının bütün attribute və method-larına, üstəlik öz yeni `fetch` method-una malikdir.

```python
retriever = GoldenRetriever("Goldie", 2)
print(retriever.describe())  # Parent class-dan method
print(retriever.fetch("ball")) # Child class-dan method

# Output:
# Goldie is 2 years old.
# Goldie is fetching the ball!
```

Child class-da eyni adlı method təyin edərək parent method-larını **override** də edə bilərsiniz.

```python
class Chihuahua(Dog):   # Dog-dan inherit edir
    def bark(self):     # Parent class-dakı bark method-unu override edir
        return "Yip!"

chihuahua = Chihuahua("Chico", 1)
print(chihuahua.bark())
# Output: Yip!
```

### Using the `super()` Function

Child class-da method-u (məsələn, `__init__` və ya `bark`) override etdikdə, yenə də həmin method-un parent versiyasındakı kodu icra etmək istəyə bilərsiniz. `super()` function-ı child class-ın içindən parent class-ın method-unu çağırmağa imkan verir.

Onun ən çox yayılmış istifadəsi child-ın constructor-undan parent-in `__init__` constructor-unu çağırmaqdır. Bu, parent-in artıq idarə etdiyi initialization logic-ini yenidən yazmağın qarşısını alır.

**Example:**

```python
class Animal:
    def __init__(self, name):
        print("Animal created")
        self.name = name

class Dog(Animal):
    def __init__(self, name, breed):
        # Parent-in __init__ method-unu çağırın
        super().__init__(name)
        print("Dog created")
        self.breed = breed

my_dog = Dog("Buddy", "Golden Retriever")
print(my_dog.name)
print(my_dog.breed)

# Output:
# Animal created
# Dog created
# Buddy
# Golden Retriever
```

Bu nümunədə `super().__init__(name)` `Animal` class-ının `__init__` method-unu icra edir və o, `self.name`-in təyin edilməsinə baxır. `Dog` class-ı isə yalnız özünə xas olan `self.breed` attribute-i ilə məşğul olmalıdır. Bu, kodu daha asan maintain olunan edir və "Don't Repeat Yourself" (DRY) prinsipinə əməl edir.

## Polymorphism

Polymorphism "çox formalılıq" deməkdir. Programming-də bu, müxtəlif object-lərin eyni method çağırışına müxtəlif cür cavab vermək qabiliyyətinə aiddir.

**Example:** Tutaq ki, hər ikisi `speak` method-una malik `Cat` və `Dog` class-larımız var.

```python
class Cat:
    def speak(self):
        return "Meow!"

class Dog:
    def speak(self):
        return "Woof!"

# "Speak" edə bilən istənilən heyvanla işləyə bilən function
def animal_sound(animal):
    print(animal.speak())

my_dog = Dog()
my_cat = Cat()

animal_sound(my_dog)  # Output: Woof!
animal_sound(my_cat)  # Output: Meow!
```

Burada `animal_sound` function-ı object-in `Dog` yoxsa `Cat` olduğunu bilməli deyil. O, sadəcə `speak()` method-unu çağırır və object özü düzgün cavab verməyi bilir. Bu, kodu daha çevik (flexible) və genişləndirilə bilən (extensible) edir.

## Encapsulation

Encapsulation — datanın (attribute-lərin) və həmin data üzərində işləyən method-ların tək bir vahidə (class-a) birləşdirilməsidir. O, həmçinin object-in bəzi komponentlərinə birbaşa girişi məhdudlaşdırmağı əhatə edir ki, bu da datanın təsadüfən dəyişdirilməsinin qarşısını almağın yoludur.

Python-da bəzi digər dillərdəki kimi ciddi "private" keyword-ü yoxdur. Lakin konvensiyaya görə, attribute-in adının əvvəlinə alt xətt (`_`) əlavə edərək onun daxili istifadə üçün nəzərdə tutulduğunu göstərə bilərik.

**Example:**

```python
class Car:
    def __init__(self, make, model):
        self.make = make          # Public attribute
        self._model = model       # "Protected" attribute
        self.__speed = 0          # "Private" attribute (name mangling)

    def accelerate(self):
        self.__speed += 10

    def get_speed(self):
        return self.__speed

my_car = Car("Toyota", "Corolla")
print(my_car.make)  # Output: Toyota
print(my_car._model) # Output: Corolla
print(my_car.__speed) # Output: AttributeError: 'Car' object has no attribute '__speed'
print(my_car._Car__speed) # Output: 0
my_car.accelerate()
print(my_car.get_speed()) # Output: 10
```

- **`make`:** Hamı üçün əlçatandır (public).
- **`_model`:** Konvensiya bunu class-ın kənarından birbaşa əldə etməməyi tövsiyə edir.
- **`__speed`:** İki alt xətt "name mangling"-ə səbəb olur. Python adı `_Car__speed`-ə dəyişir və bu, kənardan daxil olmağı çətinləşdirir.

Bu prinsip object-ləriniz üçün aydın interface yaratmağa və onların daxili state-ində istənilməyən dəyişikliklərin qarşısını almağa kömək edir.

## Abstraction

Abstraction mürəkkəb implementasiya detallarını gizlətməyi və object-in yalnız zəruri xüsusiyyətlərini göstərməyi nəzərdə tutur. O, programming-in mürəkkəbliyini və əmək sərfini azaltmağa kömək edir.

Python-da abstraction **Abstract Base Classes (ABCs)** vasitəsilə həyata keçirilə bilər. Abstract class — instantiate edilə bilməyən və digər class-lar tərəfindən inherit edilməsi nəzərdə tutulan class-dır. O, subclass-ları müəyyən method-ları implement etməyə məcbur edir.

**Example:**

```python
from abc import ABC, abstractmethod

class Shape(ABC):
    @abstractmethod
    def area(self):
        pass

    @abstractmethod
    def perimeter(self):
        pass

class Rectangle(Shape):
    def __init__(self, width, height):
        self.width = width
        self.height = height

    def area(self):
        return self.width * self.height

    def perimeter(self):
        return 2 * (self.width + self.height)

# shape = Shape() # Bu, xəta raise edəcək: TypeError: Can't instantiate abstract class Shape with abstract methods area, perimeter

rect = Rectangle(5, 10)
print(rect.area())      # Output: 50
print(rect.perimeter()) # Output: 30
```

Abstraction-dan istifadə etməklə bütün subclass-ların (`Rectangle`, `Circle` və s.) əməl etməli olduğu aydın interface (`Shape`) təyin edirik; bu, ardıcıllığı təmin edir və hər fiqur üçün konkret hesablamaları gizlədir.

> **Note:** Abstract class-da property təyin etmək üçün `@property` decorator-dan istifadə edə bilərsiniz.
> ```python
> class Machine(ABC):
>     @property
>     @abstractmethod
>     def is_running(self):
>         pass
> 
> class Car(Machine):
>     def __init__(self, make, model):
>         self.make = make
>         self.model = model
>         self.started = False
>     
>     @property
>     def is_running(self):
>         return self.started
> 
> my_car = Car("Toyota", "Prius")
> print(my_car.is_running)
> # Output: False
> ```

## Special Methods

Special method-lar object-lərdən daha təbii şəkildə istifadə etməyə imkan verən əvvəlcədən təyin olunmuş method-lar toplusudur. Onlar object-lər üzərində müəyyən built-in function və operator-lardan istifadə etdikdə çağırılır.

```python
class Book:
    def __init__(self, title, author, pages):
        print("A book is created")
        self.title = title
        self.author = author
        self.pages = pages

    def __str__(self):
        return f"Title: {self.title}, Author: {self.author}, Pages: {self.pages}"

    def __len__(self):
        return self.pages

    def __del__(self):
        print("A book is destroyed")

my_book = Book("The Great Gatsby", "F. Scott Fitzgerald", 180)
print(my_book)
# Output: Title: The Great Gatsby, Author: F. Scott Fitzgerald, Pages: 180
print(len(my_book))
# Output: 180
del my_book
# Output: A book is destroyed
print(my_book)
# Output: NameError: name 'my_book' is not defined
```

> **Note:** `__str__` ilə `__repr__` arasındakı fərq budur: `__str__` object-i çap etmək üçün, `__repr__` isə object-in string təsvirini qaytarmaq üçün istifadə olunur. Bundan başqa, onlar eynidir.

## Data Classes

Python 3.7-də təqdim olunmuş data class-lar `__init__()`, `__repr__()` və `__eq__()` kimi special method-ları class-larınıza avtomatik əlavə etməyin yoludur. Onlar əsasən data saxlayan class-lar üçün əladır.

`@dataclass` decorator-dan istifadə edirsiniz.

**Before Data Classes:**

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __repr__(self):
        return f"Person(name='{self.name}', age={self.age})"

    def __eq__(self, other):
        return self.name == other.name and self.age == other.age

	def say_hello(self):
		return f'Hi, my name is {self.name}.'
```

**With Data Classes:**

```python
from dataclasses import dataclass, asdict

@dataclass
class IDCard:
	pin: str
	series: str
	number: int

@dataclass
class Person:
	name: str
	age: int
	id_card: IDCard

	def say_hello(self):
		return f'Hi, my name is {self.name}.'

id_card1 = IDCard("19F9AKS", "ABC", 123456789)
p1 = Person("Alice", 30, id_card1)
p2 = Person("Alice", 30, id_card1)

print(p1)               # Output: Person(name='Alice', age=30)
print(p1 == p2)         # Output: True
print(p1.say_hello())
```

Gördüyünüz kimi, data class versiyası xeyli qısadır və boilerplate kod yazmadan faydalı default davranışlar təqdim edir.

## Built-in Class Decorators

Python class-larda method və property-ləri idarə etmək üçün çox istifadə olunan bir neçə built-in decorator ilə gəlir.

### `@staticmethod`

Static method — class-ın instance-ına deyil, class-ın özünə aid olan method-dur. O, instance-a (`self`) və ya class-a (`cls`) daxil ola bilmir. O, mahiyyətcə class daxilində namespace-ə salınmış adi function-dır.

**Use case:** Utility function class ilə əlaqəli olduqda, lakin heç bir class və ya instance datasına daxil olmağa ehtiyac duymadıqda.

**Example:**
```python
class MathUtils:
    @staticmethod
    def add(a, b):
        return a + b

print(MathUtils.add(5, 3))  # Output: 8
```

#### Static vs. Instance Methods

```python
class Rectangle:
	def __init__(self, a, b):
		self.a = a
		self.b = b

	def compute_area1(a, b):
		return a * b
	
	@staticmethod
	def compute_area2(a, b):
		return a * b

r = Rectangle(3,4)
r.compute_area1(3,4) # TypeError: Rectangle.compute_area1() takes 2 positional arguments but 3 were given
r.compute_area2(3,4) # 12
Rectangle.compute_area1(3,4) # 12
Rectangle.compute_area2(3,4) # 12
```

### `@classmethod`

Class method — instance-a deyil, class-a bağlı olan method-dur. O, ilk argument kimi class-ın özünü qəbul edir və konvensiyaya görə `cls` adlanır.

#### Alternative Constructors (Factory Methods)

**Example:**
```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    @classmethod
    def from_birth_year(cls, name, birth_year):
        age = 2025 - birth_year
        return cls(name, age)

person = Person.from_birth_year("Alice", 1995)
print(person.name, person.age) # Alice 30
```

#### Maintaining and Modifying Class State 

```python
class User:
    total_users = 0

    def __init__(self, name):
        self.name = name
        User._increment_user_count()

    @classmethod
    def _increment_user_count(cls):
        cls.total_users += 1

u1 = User("Alice")
u2 = User("Bob")
User.total_users # 2
```

#### Supporting Proper Inheritance
```python
class Rectangle:
	def __init__(self, a, b):
		self.a = a
		self.b = b
	
	@staticmethod
	def compute_area(a, b):
		return a * b

class Square(Rectangle):
	def __init__(self, a):
		super().__init__(a, a)

	@classmethod
	def compute_area(cls, a):
		return super(Square, cls).compute_area(a, a)

Square.compute_area(3) # 9
```

### `@property`

`@property` decorator-u attribute kimi əlçatan olan method-ları təyin etməyə imkan verir. Bu, "getter" method-ları function kimi çağırmadan yaratmaq üçün faydalıdır. Siz həmçinin "setter" və "deleter" logic-i də təyin edə bilərsiniz.

#### Computed and Read Only Attributes

```python
class Rectangle:
	def __init__(self, a, b):
		self.a = a
		self.b = b
	
	@property
	def area(self):
		return self.a * self.b
	
r = Rectangle(3, 4)
r.area
```

#### Advanced attribute management logic

**Example:**
```python
class Circle:
    def __init__(self, radius):
        self._radius = radius

    @property
    def radius(self):
        return self._radius

    @radius.setter
    def radius(self, value):
        if value < 0:
            raise ValueError("Radius cannot be negative")
        self._radius = value

    @radius.deleter
    def radius(self):
        del self._radius

c = Circle(5)
print(c.radius)      # Attribute kimi əldə etmək (getter)
c.radius = 7         # Attribute kimi təyin etmək (setter)
print(c.radius)
del c.radius         # Attribute kimi silmək (deleter)
```
