# 1.1: Python-a Giriş və Əsas Anlayışlar

## Programlaşdırmaya Giriş

### Programming nədir?

Programming — kompüterin icra etməsi üçün təlimatlar yazmaq prosesidir. Programming language ilə yazılmış bu təlimatlar kompüterə tapşırığı necə yerinə yetirməyi və ya problemi necə həll etməyi deyir. Bunu kompüterin izləməsi üçün resept hazırlamaq kimi düşünə bilərsiniz.

### Data Analytics nədir?

Data Analytics böyük dataset-ləri araşdıraraq trendləri tapmağa, suallara cavab verməyə və nəticələr çıxarmağa fokuslanır. Bu, çox vaxt tapıntıları vizuallaşdırmaq üçün dashboard-lar və report-lar yaratmağı da ehtiva edir. Əsas məqsəd biznes qərarlarını məlumatlandırmaq üçün keçmiş datanı anlamlandırmaqdır. Məsələn, şirkət müxtəlif regionlarda hansı məhsulların daha məşhur olduğunu anlamaq üçün satış datasını təhlil edə bilər.

### Data Science nədir?

Data Science data analytics-i əhatə edən daha geniş sahədir. O, structured və unstructured datadan bilik və insight-lar çıxarmaq üçün elmi metodlardan, proseslərdən, alqoritmlərdən (algorithms) və sistemlərdən istifadə etməyi nəzərdə tutur. Data scientist-lər yalnız datanı təhlil etmir, həm də gələcək haqqında proqnozlar vermək üçün machine learning kimi qabaqcıl texnikalardan istifadə edirlər.

### Machine Learning nədir?

Machine Learning (ML) artificial intelligence-in (AI) və data science-in alt çoxluğudur (subset). O, kompüterlərə açıq şəkildə proqramlaşdırılmadan datadan öyrənməyə imkan verən alqoritmlər qurmağa fokuslanır. Qaydalar yazmaq əvəzinə alqoritmə data verirsiniz və o, pattern-ləri özü öyrənir. Məsələn, email spam filter-i keçmiş nümunələrə əsasən junk mail-i tanımağı öyrənən machine learning modelidir.

### Data Science üçün niyə Python?

Python bir neçə əsas səbəbə görə data science üçün de-facto dilə çevrilib:

*   **Simplicity and Readability (Sadəlik və Oxunaqlılıq):** Python-un syntax-ı təmiz və intuitivdir, bu da onu yeni başlayanlar üçün öyrənməyi nisbətən asanlaşdırır. O, demək olar ki, adi ingilis dili kimi oxunur.
*   **Extensive Libraries (Geniş Library-lər):** Python data science üçün xüsusi hazırlanmış zəngin library ekosisteminə malikdir, məsələn:
    *   **Pandas:** Data manipulation və analiz üçün.
    *   **NumPy:** Xüsusilə array-lərlə rəqəmsal əməliyyatlar üçün.
    *   **Matplotlib və Seaborn:** Data visualization üçün.
    *   **Scikit-learn:** Machine learning alqoritmləri üçün.
*   **Versatility (Çoxfunksiyalılıq):** Python general-purpose dildir, yəni yalnız data science üçün deyil. Onunla veb tətbiqlər qura, tapşırıqları avtomatlaşdıra və daha çox şey edə bilərsiniz.
*   **Large Community (Böyük Komunity):** Böyük və aktiv qlobal komunity o deməkdir ki, kömək, tutorial-lar və problemlərin həllini asanlıqla tapa bilərsiniz.

## Environment-in Qurulması

### Visual Studio Code (VS Code)-un Quraşdırılması

VS Code masaüstündə işləyən yüngül, lakin güclü source code editor-dur və Windows, macOS və Linux üçün mövcuddur. O, JavaScript, TypeScript və Node.js üçün built-in dəstəyə malikdir və digər dillər (məsələn, Python) və runtime-lar üçün zəngin extension ekosisteminə sahibdir.

1.  **Download:** [Rəsmi VS Code veb-saytına](https://code.visualstudio.com/) daxil olun və Windows üçün installer-i yükləyin.
2.  **Install:** Installer-i işə salın. Default parametrləri qəbul etmək tövsiyə olunur, lakin VS Code-u command line-dan aça bilmək üçün "Add to PATH" seçimini işarələdiyinizə əmin olun.

### Git-in Quraşdırılması

Git — kodunuzdakı dəyişiklikləri izləməyə kömək edən version control sistemidir. O, əməkdaşlıq (collaboration) və layihələrinizin müxtəlif versiyalarını idarə etmək üçün vacib alətdir.

1.  **Download:** [Rəsmi Git veb-saytına](https://git-scm.com/downloads) daxil olun və Windows üçün installer-i yükləyin.
2.  **Install:** Installer-i işə salın. Default seçimlər əksər istifadəçilər üçün uyğundur. Bu, həm də Git-dən istifadə üçün command-line aləti olan Git Bash-i quraşdıracaq.

### Miniconda-nın Quraşdırılması

Miniconda — package və environment manager olan conda üçün pulsuz minimal installer-dir. Yeni başlayanlar üçün Anaconda-dan daha çox tövsiyə olunur, çünki yüngüldür və yalnız əsasları quraşdırır.

1.  **Download:** [Miniconda documentation](https://docs.conda.io/en/latest/miniconda.html) səhifəsinə daxil olun və əməliyyat sisteminiz (Windows, macOS və ya Linux) üçün installer-i yükləyin.
2.  **Install:** Installer-i işə salın və ekrandakı təlimatlara əməl edin. Default parametrləri qəbul etmək tövsiyə olunur.

Alternativ olaraq, 
1. **Windows düyməsini basın**
2. *powershell* yazın
3. powershell-də `>`-dən sonra aşağıdakını copy-paste edin
```bash
Invoke-WebRequest -Uri "https://repo.anaconda.com/miniconda/Miniconda3-latest-Windows-x86_64.exe" -outfile ".\miniconda.exe"
Start-Process -FilePath ".\miniconda.exe" -ArgumentList "/S" -Wait
del .\miniconda.exe
```

### Environment-lərin Yaradılması və İdarə Olunması

`conda`-nın əsas xüsusiyyətlərindən biri izolyasiya olunmuş (isolated) environment-lər yaratmaq qabiliyyətidir. Bu o deməkdir ki, müxtəlif layihələr üçün Python və package-lərin fərqli versiyalarını bir-birinə mane olmadan saxlaya bilərsiniz.

1.  **Yeni environment yaradın:** Terminal-ı (və ya Windows-da Anaconda Prompt-u) açın və aşağıdakı command-ı yazın. Biz environment-imizi `ds_env` (data science environment üçün) adlandıracağıq və Python 3.9 quraşdıracağıq.

    ```bash
    conda create --name ds_env python=3.11
    ```

2.  **Environment-i aktivləşdirin (activate):** Yeni environment-dən istifadə edə bilməzdən əvvəl onu aktivləşdirməlisiniz.

    ```bash
    conda activate ds_env
    ```
    Terminal prompt-unuz indi aktiv environment-in adını göstərmək üçün dəyişməlidir (məs., `(ds_env) C:\Users\user>`).

3.  **Package-ləri quraşdırın:** Environment aktiv olduqda indi ona package-lər quraşdıra bilərsiniz. Gəlin Jupyter Notebook quraşdıraq.

    ```bash
    conda install jupyter
    ```

4.  **Environment-i deaktiv edin (deactivate):** İşinizi bitirdikdə base environment-ə qayıtmaq üçün environment-i deaktiv edə bilərsiniz.

    ```bash
    conda deactivate
    ```

### VS Code-da Conda Environment-lərindən İstifadə

Visual Studio Code Python və Conda ilə əla inteqrasiyaya malikdir.

1.  VS Code-da **layihə qovluğunuzu (project folder) açın**.
2.  **Python interpreter seçin:** Command Palette-i (`Ctrl+Shift+P`) açın və `Python: Select Interpreter` axtarın. Siyahıda `ds_env` conda environment-inizi görməlisiniz. Onu seçin.
3.  **Yeni Jupyter Notebook yaradın:** İndi VS Code-da `.ipynb` faylı yarada bilərsiniz. Cell-i ilk dəfə işə saldığınız zaman VS Code seçilmiş interpreter-dən (`ds_env`) və onun package-lərindən istifadə edəcək.

## Basic Operators

### Arithmetic Operators
Riyazi əməliyyatları yerinə yetirmək üçün istifadə olunur.

| Operator | Description    | Example     | Result |
| :------- | :------------- | :---------- | :----- |
| `+`      | Addition (Toplama)       | `5 + 2`     | `7`    |
| `-`      | Subtraction (Çıxma)    | `5 - 2`     | `3`    |
| `*`      | Multiplication (Vurma) | `5 * 2`     | `10`   |
| `/`      | Division (Bölmə)       | `5 / 2`     | `2.5`  |
| `//`     | Floor Division (Tam bölmə) | `5 // 2`    | `2`    |
| `%`      | Modulus (Qalıq)        | `5 % 2`     | `1`    |
| `**`     | Exponentiation (Qüvvətə yüksəltmə) | `5 ** 2`    | `25`   |

> **Note:** Exponentiation kökləri tapmaq üçün də istifadə oluna bilər. Məsələn, `2 ** 0.5` 2-nin kvadrat kökünü verir.

### Operator Precedence

Bir ifadədə bir neçə operator istifadə olunduqda Python hansı əməliyyatı birinci yerinə yetirəcəyini müəyyən etmək üçün müəyyən precedence (üstünlük) sırasına əməl edir. Bu, çox vaxt **PEMDAS** və ya **BODMAS** akronimi ilə yadda saxlanılır.

*   **P**arentheses `()`
*   **E**xponents `**`
*   **M**ultiplication `*`, **D**ivision `/`, **F**loor Division `//`, **M**odulus `%` (soldan sağa)
*   **A**ddition `+`, **S**ubtraction `-` (soldan sağa)

Ən yüksəkdən ən aşağıya doğru precedence:

| Precedence | Operator         | Description                                       |
| :--------- | :--------------- | :------------------------------------------------ |
| Highest    | `()`             | Parentheses (qruplaşdırma üçün)                   |
|            | `**`             | Exponentiation                                    |
|            | `*`, `/`, `//`, `%` | Multiplication, Division, Floor Division, Modulus |
| Lowest     | `+`, `-`         | Addition və Subtraction                           |

### Comparison Operators
İki dəyəri müqayisə etmək üçün istifadə olunur. Onlar Boolean (`True` və ya `False`) qaytarır.

| Operator | Description              | Example     | Result |
| :------- | :----------------------- | :---------- | :----- |
| `==`     | Equal to (Bərabərdir)                 | `5 == 2`    | `False`|
| `!=`     | Not equal to (Bərabər deyil)             | `5 != 2`    | `True` |
| `>`      | Greater than (Böyükdür)             | `5 > 2`     | `True` |
| `<`      | Less than (Kiçikdir)                | `5 < 2`     | `False`|
| `>=`     | Greater than or equal to (Böyük və ya bərabərdir) | `5 >= 5`    | `True` |
| `<=`     | Less than or equal to (Kiçik və ya bərabərdir)    | `5 <= 2`    | `False`|

> **Note:** Bərabərlik `=` ilə deyil, `==` ilə yoxlanılır.

## Variables and Data Types

Variable-lar data dəyərlərini saxlamaq üçün konteynerlərdir.

!['Variables'](https://automatetheboringstuff.com/3e/images/000001.jpg)


> **Assignment vs. Equality:** Çox rast gəlinən qarışıqlıq assignment operator-u (`=`) ilə equality operator-u (`==`) arasındakı fərqdir.
>*   **Assignment operator (`=`)** variable-a dəyər mənimsətmək üçün istifadə olunur.
>*   **Equality operator (`==`)** iki dəyəri müqayisə etmək üçün istifadə olunur və Boolean (`True` və ya `False`) qaytarır.
>
>    ```python
>    # Assignment: 42 dəyəri 'spam' variable-ına mənimsədilir.
>    spam = 42
>
>    # Equality Check: Bu, 'spam'-ın dəyərinin 42-yə bərabər olub-olmadığını yoxlayır.
>    print(spam == 42) # Output: True
>
>    # Bu, 'spam'-ın dəyərinin 99-a bərabər olub-olmadığını yoxlayır.
>    print(spam == 99) # Output: False
>    ```

### Variable Naming Rules

Python-da variable adlandırarkən bu qaydalara əməl etməlisiniz:

*   Variable adı hərflə və ya alt xətt simvolu (`_`) ilə başlamalıdır.
*   Variable adı rəqəmlə başlaya bilməz.
*   Variable adı yalnız alfa-rəqəmsal simvollardan və alt xəttlərdən (`A-z`, `0-9` və `_`) ibarət ola bilər.
*   Variable adları case-sensitive-dir (`age`, `Age` və `AGE` üç fərqli variable-dır).
*   Python keyword-lərini (`if`, `for`, `while`, `str`, `int` kimi) variable adı kimi istifadə etməkdən çəkinin.

**Good Examples:**
```python
my_variable = 10
user_name = "JohnDoe"
_value = 42
```

**Bad Examples:**
```python
2nd_variable = 5  # Rəqəmlə başlaya bilməz
my-variable = 20  # Defis (hyphen) ehtiva edə bilməz
for = "loop"      # "for" keyword-dür
```


> **Note:**
> String-ləri təyin etmək üçün tək dırnaqdan (`'`) və ya cüt dırnaqdan (`"`) istifadə edə bilərsiniz. Lakin string-in özündə dırnaq varsa, xətadan qaçmaq üçün əks dırnaq növündən istifadə etməlisiniz.

> **Another Note:**
>
> **Number vs. Text:** `1` integer-i üzərində riyazi hesablamalar apara biləcəyiniz rəqəmdir. `"1"` string-i isə mətn parçasıdır, tək simvoldur.
> 
> ```python
> # Riyazi toplama
> print(1 + 1)
> # Output: 2
> 
> # String concatenation
> print("1" + "1")
> # Output: "11"
> ```
> String ilə riyazi əməliyyat aparmağa çalışmaq xəta ilə nəticələnəcək: `1 + "1"` proqramınızı crash etdirəcək.

*   **Boolean (`bool`):** İki dəyərdən birini təmsil edir: `True` və ya `False`.
    ```python
    is_student = True
    is_teacher = False
    ```

> **Boolean vs. Text:** Eynilə, `True` həqiqəti təmsil edən xüsusi boolean dəyəridir. `"True"` isə sadəcə dörd simvoldan ibarət string-dir.
> 
> ```python
> is_student = True
> print(is_student)
> # True çap edir
> print(not is_student)
> # False çap edir
> ```

*   **NoneType (`None`):** Dəyərin yoxluğunu təmsil edir. Çox vaxt default placeholder kimi və ya "nəticə yoxdur" mənasını bildirmək üçün istifadə olunur.
    ```python
    result = None
    print(result is None)
    # True çap edir

    gender = None
    print(gender is not None)
    # False çap edir
    ```

**Bu niyə vacibdir?**

Data type-lar kompüterə hansı növ data ilə işlədiyini və hansı əməliyyatlara icazə verildiyini bildirir. Bu qaydaları tətbiq etməklə Python xətaların qarşısını almağa kömək edir və kodumuzun proqnozlaşdırıla bilən şəkildə davranmasını təmin edir. Düzgün data type-dan istifadə etmək düzgün və səmərəli proqramlar yazmaq üçün əsasdır.

## Strings in Detail

### String Concatenation

`+` operator-u iki və ya daha çox string-i birləşdirmək üçün istifadə oluna bilər. Buna **string concatenation** deyilir.

```python
first_name = "John"
last_name = "Doe"
full_name = first_name + " " + last_name
print(full_name)
# Output: John Doe
```

### String Replication

`*` operator-u string-i bir neçə dəfə təkrarlamaq üçün istifadə oluna bilər. Buna **string replication** deyilir.

```python
word = "Hello"
repeated_word = word * 3
print(repeated_word)
# Output: HelloHelloHello
```

### Escape Characters

Escape characters string-lərdə hərfi mənada (literally) şərh olunmayan xüsusi simvollardır. Onlardan əvvəl backslash (`\`) gəlir və onlar string-in içində yeni sətir (newline), tab və ya dırnaq kimi başqa cür təmsil etmək çətin olan simvolları daxil etməyə imkan verir.

| Escape Character | Description      |
| :--------------- | :--------------- |
| `\'`             | Tək dırnaq (Single quote)     |
| `\"`             | Cüt dırnaq (Double quote)     |
| `\t`             | Tab              |
| `\n`             | Newline (yeni sətir)          |
| `\\`             | Backslash        |

```python
print('I\'m a string with a single quote.')
# Output: I'm a string with a single quote.
print("She said, \"Hello!\"")
# Output: She said, "Hello!"
print("This is a line.\nThis is a new line.")
# Output: This is a line.
#         This is a new line.
print("This is a backslash: \\")
# Output: This is a backslash: \
```

### String Indexing and Slicing

String-lər simvolların sıralı ardıcıllığıdır (ordered sequences). Tək-tək simvollara index vasitəsilə, simvollar aralığına isə slicing vasitəsilə daxil ola bilərsiniz.

#### Indexing
Python zero-based indexing istifadə edir, yəni ilk simvol `0` index-indədir. Negative indexing string-in sonundan simvollara daxil olmaq üçün istifadə oluna bilər, burada `-1` son simvoldur.

```python
my_string = "Hello, World!"

# Positive indexing
print(my_string[0])   # Output: H
print(my_string[7])   # Output: W

# Negative indexing
print(my_string[-1])  # Output: !
print(my_string[-6])  # Output: W
```

#### Slicing
Slicing substring əldə etməyə imkan verir. Syntax `[start:stop]` şəklindədir, burada `start` daxil ediləcək ilk simvolun index-i, `stop` isə dayanılacaq simvolun index-idir (o, daxil edilmir).

```python
my_string = "Hello, World!"

# 'Hello' əldə edin
print(my_string[0:5])  # Output: Hello

# 'World' əldə edin
print(my_string[7:12]) # Output: World

# start buraxılsa, default olaraq başlanğıc götürülür
print(my_string[:5])   # Output: Hello

# stop buraxılsa, default olaraq son götürülür
print(my_string[7:])   # Output: World!
```

#### Slicing with a Step
`[start:stop:step]` syntax-ı ilə step ölçüsü də verə bilərsiniz. Step simvol götürüldükdən sonra neçə simvol irəli tullanılacağını göstərir.

```python
my_string = "Hello, World!"

# Hər ikinci simvolu götürün
print(my_string[::2])  # Output: Hlo ol!

# 1-ci index-dən 10-cu index-ə qədər 3 step ilə simvolları götürün
print(my_string[1:10:3]) # Output: eoW

# String-i tərsinə çevirin (reverse)
print(my_string[::-1]) # Output: !dlroW ,olleH
```

### String Properties

Python-da string-lərin ən vacib xüsusiyyətlərindən biri onların **immutable** olmasıdır. Bu o deməkdir ki, string bir dəfə yaradıldıqdan sonra dəyişdirilə bilməz. String-i dəyişdirən kimi görünən hər hansı method əslində dəyişikliklərlə yeni string qaytarır.

**Immutability Nümunəsi:**

String-dəki simvolu dəyişməyə çalışsanız, xəta alacaqsınız:

```python
my_string = "Hello"
# String-lər immutable olduğu üçün bu, xəta verəcək
# my_string[0] = 'J' # TypeError: 'str' object does not support item assignment
```

String-i "dəyişmək" üçün yenisini yaratmalısınız:

```python
my_string = "Hello"
new_string = "J" + my_string[1:]
print(new_string) # Output: Jello
```

### String Methods

String-lər ümumi əməliyyatları yerinə yetirməyə imkan verən müxtəlif built-in method-larla gəlir. Bu method-lar yeni string-lər qaytarır və orijinal string-i dəyişməz saxlayır.

| Method           | Description                                                 |
| :--------------- | :---------------------------------------------------------- |
| `.upper()`        | String-i böyük hərflərə (uppercase) çevirir.                           |
| `.lower()`        | String-i kiçik hərflərə (lowercase) çevirir.                           |
| `.strip()`        | String-in əvvəlindən və sonundan boşluqları (whitespace) silir.|
| `.replace(old, new)` | Substring-in bütün rast gəlinmələrini başqası ilə əvəz edir.       |
| `.split(separator)`| String-i substring-lərdən ibarət list-ə bölür.                |
| `.startswith(prefix)`| String göstərilən prefix ilə başlayırsa, `True` qaytarır.|
| `.endswith(suffix)`| String göstərilən suffix ilə bitirsə, `True` qaytarır.  |

```python
text = "  Hello, World!  "

# Case conversion
print(text.upper()) # Output:   HELLO, WORLD!  
print(text.lower()) # Output:   hello, world!  

# Stripping whitespace
print(text.strip()) # Output: Hello, World!

# Replacing text
print(text.replace("World", "Python")) # Output:   Hello, Python!  

# Splitting a string
sentence = "This is a sentence."
words = sentence.split(' ')
print(words) # Output: ['This', 'is', 'a', 'sentence.']

# Checking start and end
print(text.strip().startswith("Hello")) # Output: True
print(text.strip().endswith("!"))     # Output: True
```

> **Note:**
> String method-larının tam siyahısını görmək üçün `dir()` function-ından istifadə edə bilərsiniz.

## Basic Input and Output

### Output
Gördüyümüz kimi, `print()` function-ı output üçün istifadə olunur. Daha oxunaqlı və rahat formatlama üçün f-string-lərdən (formatted string literals) də istifadə edə bilərsiniz.

```python
name = "Bob"
age = 40
print(f"{name} is {age} years old.")
# Output: Bob is 40 years old.
```

### Formatting Options

F-string-lər müxtəlif formatlama seçimlərini dəstəkləyir:

```python
# Floating-point ədədlər üçün onluq dəqiqliyi (decimal precision)
pi = 3.14159
print(f"Pi to 2 decimal places: {pi:.2f}")
# Output: Pi to 2 decimal places: 3.14
```

> **Note:** F-string float formatlaması həmişə yuvarlaqlaşdırır (rounds up), ona görə də onluq hissələri yuvarlaqlaşdırmadan kəsmək (truncate) istəyirsinizsə, alternativ texnikalardan istifadə etməlisiniz, məsələn:
> ```python
> # 2 onluq rəqəmə qədər yuvarlaqlaşdırmadan kəsin
> import math
> pi = 3.14159
> n = 2
> print(f"Pi to 2 decimal places: {math.trunc(pi * 10**n) / 10**2}")
> # Output: Pi to 2 decimal places: 3.14
> ```

```python
# Genişlik (width) və düzləndirmə (alignment)
print(f"{'Left':<10}|{'Center':^10}|{'Right':>10}")
# Output: Left      |  Center  |     Right

# Rəqəm formatlaması
number = 1234567.89
print(f"Currency: ${number:,.2f}")
# Output: Currency: $1,234,567.89

# Faiz (Percentage)
percentage = 0.8756
print(f"Completion: {percentage:.2%}")
# Output: Completion: 87.56%

# Binary, octal və hexadecimal
value = 42
print(f"Binary: {value:b}, Hex: {value:x}")
# Output: Binary: 101010, Hex: 2a
```
